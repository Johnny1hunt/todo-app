# To-Do App

A simple task manager built with HTML, CSS, and vanilla JavaScript.

## Features
- Add, complete, and delete tasks
- Filter by All, Active, or Completed
- Live counter of tasks left
- Clear all completed tasks at once
- Tasks are saved in the browser (localStorage), so they stay after a refresh
- Responsive design that works on phone and desktop

## Run it locally
1. Download or clone this repository.
2. Open `index.html` in any browser.

## What I practiced
DOM manipulation, event handling, array methods (`filter`, `map`), and saving data with localStorage.
